# Yegova Fusion — Android WebView app

Opens only the **Fusion Corner** website.

## Set your URL

Edit `app/src/main/res/values/strings.xml`:

```xml
<string name="site_url">http://cococola.yegova.store/</string>
```

Use `https://` if your hosting supports it.

## Build

1. Open this folder in Android Studio  
2. Build → Build APK(s)  
3. Install on phone  

See `../README.md` for details.
