# Yegova Traders — Android WebView app

Opens only the **Traders GST** website.

## Set your URL (required)

Edit `app/src/main/res/values/strings.xml`:

```xml
<string name="site_url">https://your-traders-domain.com/</string>
```

Replace with your real Traders site URL before building.

## Build

1. Open this folder in Android Studio  
2. Build → Build APK(s)  
3. Install on phone  

See `../README.md` for details.
